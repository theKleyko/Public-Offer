2. Alojamiento (GitHub Pages)

Este sitio se aloja en GitHub Pages, un servicio de GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, EE. UU. Al visitar las páginas, GitHub trata datos técnicamente necesarios (dirección IP, fecha y hora, página visitada, datos del navegador) en sus registros de servidor. Base jurídica: interés legítimo en la prestación segura y estable del sitio (art. 6.1.f RGPD). Más información: GitHub General Privacy Statement.

3. Estadísticas de visitas (Plausible), sin cookies

Este sitio no utiliza cookies ni guarda nada en su navegador. Para saber cómo se usan las páginas se utiliza Plausible Analytics, de Plausible Insights OÜ (Estonia, UE), que trata los datos en la Unión Europea y no almacena direcciones IP ni identificadores de usuario. Se cuentan, de forma agregada, las páginas vistas, la procedencia (por ejemplo YouTube o Substack), el país aproximado, el tipo de dispositivo y algunas acciones en la página: pulsar el botón de reserva o un enlace de contacto, reproducir un vídeo de testimonio, llegar al final de la página o permanecer en ella un tiempo. Los enlaces cortos de este sitio (por ejemplo /substack) cuentan el clic antes de llevarle a su destino. Si su navegador envía una señal de no seguimiento (Global Privacy Control o Do Not Track), no se cuenta nada. Base jurídica: interés legítimo en conocer el uso del sitio de forma estadística (art. 6.1.f RGPD). Más información: política de datos de Plausible.

4. Vídeos

Los vídeos de este sitio se sirven directamente desde este sitio. No se incrustan reproductores de plataformas de terceros.

5. Enlaces externos

Este sitio enlaza a servicios externos (Stripe para pagos, Substack, Telegram, YouTube). El tratamiento de datos en esos servicios se rige por las políticas de privacidad de sus proveedores.

6. Contacto por correo electrónico

Si contacta por correo, los datos facilitados (dirección, contenido del mensaje) se tratan para atender la consulta. Base jurídica: art. 6.1.b y 6.1.f RGPD.

7. Sus derechos

Conforme al RGPD y a la LOPDGDD, tiene derecho de acceso, rectificación, supresión, limitación, portabilidad y oposición. Puede ejercerlos escribiendo a kleyko@thekleyko.com. También tiene derecho a reclamar ante la Agencia Española de Protección de Datos (www.aepd.es).
